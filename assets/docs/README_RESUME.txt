Ashish Agrawal - Resume File Guide
===================================

To make your resume downloadable:
1. Save your resume as a PDF file named: Ashish_Agrawal_Resume.pdf
2. Place it in this folder: assets/docs/Ashish_Agrawal_Resume.pdf
3. The "Download Resume" button on your portfolio website will automatically link to and download this file!

Until you add your PDF, the portfolio includes an interactive fallback modal displaying your verified skills, contact information, and core value proposition.
